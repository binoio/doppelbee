DuoBee 2.0.1

A small user-interface cleanup release. No functional or security changes.

Fixed

  • Removed the duplicate About DuoBee and DuoBee Help items from the Window menu. Both remain in their proper places: DuoBee → About DuoBee and Help → DuoBee Help.
  • Removed the redundant Close button from the bottom of the About window.

Changed

  • In-app text in the About and Help windows now uses the generic term "authenticator".
