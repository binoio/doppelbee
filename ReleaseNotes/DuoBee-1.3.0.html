DuoBee 1.3.0

Automatic updates

DuoBee now updates itself using Sparkle. New versions are signed with an EdDSA key and verified before installation, so an update is only applied if it genuinely came from us.

  • DuoBee → Check for Updates… checks on demand.
  • Settings → Updates controls automatic checking and background downloads.
  • On first launch DuoBee asks once whether to check automatically. Nothing is sent anywhere until you answer.

DuoBee stays sandboxed. Updates install through Sparkle's sandboxed installer service rather than by relaxing the app's protections.

Upgrading from 1.2.1 or earlier: those builds have no updater and cannot upgrade themselves, so 1.3.0 must be installed manually once. Updates are automatic after that. Your database, keychain entries, and settings are unaffected.
