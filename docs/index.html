DoppelBee

A native macOS authenticator. Enroll once from an activation link, then generate one-time codes and answer push approvals without reaching for your phone.

Download for macOS

Codes on Your Desktop

Enroll a key once from an activation link, then generate standards-compliant one-time passwords right where you are signing in.

Push, Answered in Place

Approve or deny push requests from the notification or the app window. Verified pushes always ask you to type the code shown on the device you are signing in from — never auto-confirmed.

Encrypted at Rest

Keys live in an AES-256-GCM database behind a password you choose, optionally unlocked from the macOS Keychain. Export it, back it up, move it.
